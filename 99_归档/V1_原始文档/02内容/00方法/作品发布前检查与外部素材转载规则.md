# 作品发布前检查与外部素材转载规则

> 建立时间：2026-09-05。  
> 触发范围：准备发布任何抖音作品，尤其是含外网视频、官方宣传片、他人画面、翻译字幕、新闻片段、AI 生成画面或下载后再剪素材时。  
> 目的：让版本名与实际加工一致，保留来源与授权证据，降低重复搬运、侵权、误导和漏标 AI 内容的风险。

## 一、核心规则

1. **“××版”只能描述真实做过的加工，不能当作规避审核或证明原创的标签。** 加一个版本名不会自动取得版权许可，也不会自动消除平台对重复内容的判断。
2. **默认优先做“中文解读版”。** 由本人的口播、观点、筛选和结构承担主要价值，外部视频只作为必要的证据或例子，不让完整外片成为作品主体。
3. **字幕版只在确实完成翻译和校对时使用。** 自动字幕直接烧录、只裁黑边、变速、镜像、换音乐或加标题，不得写成“精校版”。
4. **来源标注不等于获得授权。** 发布前必须区分“已取得明确授权”“许可条款允许使用”“仅作必要引用但授权仍不明确”；拿不准时不整段转载。
5. **不得删除或遮挡原有水印、署名、版权提示或 AI 标识。** 画幅适配不能以隐藏来源为目的。
6. **平台状态与规则在发布当天复核。** 使用抖音当时的规则中心、发文助手/快速检测、上传预览和账号提示，不把旧经验当成永久规则。

## 二、版本名使用条件

| 可用名称 | 必须真实完成的工作 | 风险与备注 |
|---|---|---|
| `中文解读版` / `要点解读版` | 本人重新搭建叙事，加入原创口播、观点、背景或结论；外片只支撑讲解 | **默认推荐**；仍需核对素材使用权限并标明来源 |
| `中文字幕版` | 为外语原片制作中文翻译字幕，并逐句检查基本准确性 | 仍可能被识别为重复内容；字幕不等于授权 |
| `中英字幕版` | 同屏保留原文与中文译文，校对人名、产品名和关键术语 | 不得把纯自动转写包装成人工精校 |
| `精校中英字幕版` | 已逐句人工复核翻译、时间轴、说话人和关键术语，并保留字幕稿 | 只有达到上述标准才可用“精校” |
| `精华剪辑版` / `要点速览版` | 重新筛选片段、调整结构，并形成不同于原片的明确观看价值 | 仅剪短、变速或裁画幅仍不足以证明原创 |
| `经授权转载` | 已获得可核验的书面授权，且发布范围、平台、期限符合授权 | 没有证据时绝不能使用“授权”二字 |
| `某机构官方宣传片｜中文解读版` | 原片确实来自该机构官方渠道；后半部分准确说明自己的加工 | “官方”修饰原片来源，不能让观众误以为本账号是官方账号 |

### 不得使用的误导写法

- 没有逐句人工校对却写“精校版”；
- 没有授权却写“授权转载”“官方授权”；
- 把第三方二次上传误写成“官方原片”；
- 只裁黑边、去水印、镜像或换音乐，却写“二创版”“原创版”；
- 为了降低重复检测而故意改速、抽帧、加噪点或遮挡来源。

## 三、推荐标题和署名模板

### 有本人观点时（首选）

```text
GPT-6 Astra 官方宣传片｜中文解读版：普通人真正该关注的 3 件事
```

```text
素材片段来源：OpenAI 官方发布
本视频为中文解读，观点、口播与剪辑：@Kong同学
```

### 确实完成翻译字幕时

```text
GPT-6 Astra 官方宣传片｜精校中英字幕版
```

```text
原片来源：OpenAI 官方发布
中文字幕翻译、校对与时间轴：@Kong同学
```

如果并未取得转载授权，不写“经授权转载”。如授权状态不明确，只使用完成讲解所必需的片段，让本人解读成为主体；同时在该条内容文件夹保存原始链接、发布日期、来源账号和许可/授权核对记录。

## 四、AI 内容标识

- “讲 AI 产品”不等于作品本身是 AI 生成；只有作品包含 AI 生成或合成的文字、图片、音频、视频、虚拟人物等内容时，才按实际情况声明。
- 外部素材本身含 AI 生成内容时，不因再次剪辑而免除标识；保留原有标识，并在抖音发布页使用当时可用的“内容由 AI 生成”等自主声明功能。
- 无法确认外片是否为 AI 生成时，先查原发布说明和官方来源，不凭题材名称猜测。

## 五、每次发布前强制检查

- [ ] 已执行《发布文案与标签规则.md》，确认标题、正文、封面和成片兑现的内容一致；
- [ ] 话题与本条实际内容相关，活动词已按当时要求核对；未将话题标签当成AI内容声明或报名证明；
- [ ] 已在本条《发布与复盘.md》保存确认文案与话题；实际发布后补充真实稿、时间和链接；
- [ ] 已确认原片真实来源，保存原始链接、来源账号和发布日期；
- [ ] 已确认授权/许可状态；来源署名没有被误写成授权；
- [ ] 外部素材只承担必要作用，本人口播、观点或重新组织的结构是主要价值；
- [ ] 标题中的“解读版、字幕版、精校版、授权转载、官方宣传片”等词与实际加工完全一致；
- [ ] 画面或文案已标明素材来源，未删除水印、版权提示或 AI 标识；
- [ ] 如果使用翻译字幕，已复核专有名词、关键结论、数字和时间轴；
- [ ] 如果包含 AI 生成/合成内容，已按发布时的平台功能如实声明；
- [ ] 简介、封面、视频、标题和评论引导中没有二维码、站外联系方式或规避审核的暗号；
- [ ] 已审读封面和AI生成图中的小字、简历道具、学校/雇主/经历/日期，不让生成内容冒充本人真实事实；
- [ ] 录屏没有与讲解无关的收藏栏、起始页、历史建议、联系方式；演示资料明确标注“示例/演示数据”，表单与结果预览两处都已检查；
- [ ] 执行2026-09-08用户确认的制作约束：其他平台的名称、图标和口播（例如淘宝）从选稿、录制开始排除；成片同时复核声音、烧录字幕、卡片和录屏，不能只改字幕；网址遮挡跟随缩放移动，并检查转场前后及浏览器建议框。此项属于本项目制作要求，不作为平台审核因果结论；
- [ ] 已在抖音上传预览核对画幅、字幕、安全区、音量和清晰度；
- [ ] 已使用当前版本的发文助手/快速检测，并查看账号或作品提示；
- [ ] 发布后先看“已发布 / 审核中 / 未通过 / 减少推荐”等正式状态，不因前几分钟播放为 0 立即删除重发。

## 六、助手的固定提醒

以后用户提到“上传、发布、发抖音、转载、搬运、外网视频、下载后再发”等行动时，助手必须在发布前主动提醒并执行本清单。未经用户确认来源、实际加工类型与版本名，不替用户把作品描述成“精校”“授权”或“原创”。

同时核对发布文案和话题，不因成片、封面已经确认就跳过。文案制作规则见《发布文案与标签规则.md》，数据与反馈回收见《发布复盘与规则更新.md》；检查与起草不自动授权公开发布。

2026-09-06补充检查教训：不能只关注大标题和画面主体，生成细字、浏览器收藏和演示联系方式也需要核查。发现这些元素不等于已证明平台限制原因。DOU+不适合加热时先读取具体理由，不自动撤回作品；加热资格与普通作品推荐不直接画等号，依据及诊断方法见《发布复盘与规则更新.md》。
