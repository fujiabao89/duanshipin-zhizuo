# 第001条制作说明

## 制作过程

18 段原片均为 H.264、1920×1080、60fps，音频 AAC 48kHz 双声道。第001条使用 HyperFrames 0.8.6 完成完整合成，以口播为时间主轨，电脑录屏、真人小窗、普通字幕、论文证据和克制动效分层管理。

第001条先建立 R1 粗剪，后以代表性镜头确认 Codex 到 PwC 论文的转场：下一句声音先行、旧背景轻压暗、真实论文层在约 0.5 秒内由约 92% 推至 100%，真人小窗保持顶层。用户确认该方向“简单有效”。

## 论文证据镜头

使用真实报告封面和第25页原句，依次进入中文书名、真实原句、英文标记、中文结论和“8倍”强调。曾出现 CSS 默认显隐与后置动画冲突导致双闪，修复后证据层按时间线正常退出。

## V2 局部修订

- 原片 157.95—158.50 秒删除“淘宝”原声，音画同步删除 33 帧，接缝保留本人原声；
- 154.55—159.083 秒修改字幕和第一张卡片，不再出现“淘宝”；
- 官网、个人站、浏览器建议、无关收藏栏和演示联系方式按局部坐标遮挡，并检查缩放和淡出边缘；
- 没有重录、合成配音或改封面，也没有沿用已放弃的 V1 大面积信息卡方案。

最终文件完整解码通过，视频 11146 帧，音画差小于一帧。关键修补帧、类比段和最终编码画面均做抽查；这些是技术核验，不代表平台审核结论。

## 清理

约 1.0GiB 可重建的截图、OCR、临时音频、转写模型、辅助脚本和中间视频已清理。试听片和核验图曾移入可恢复废纸篓。最终成片、原发布版、18 段原片、封面、脚本、报告、参考素材和复盘记录保留。

原版完整诊断、逐段建议、封面旧方案和修订参数保存在 `99_归档/V1_原始文档/`，只在需要重建或研究历史时读取。
