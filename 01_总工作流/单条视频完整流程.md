# 单条视频完整流程

本文件只定义顺序、输入、输出和阶段完成条件。具体做法进入对应方法或规范查看。

```text
选题 → 脚本与标题 → 脚本锁定 → 拍摄 → 素材准备与确认
→ 剪辑成片 → 成片确认 → 封面 → 发布 → 复盘与归档
```

## 0 新建案例

- 输入：候选选题和基本方向。
- 执行：建立 `06_视频案例/第NNN条_标题/项目卡.md`，记录目标、状态、特殊要求和待确认项。
- 输出：案例入口。
- 完成条件：编号、工作标题和负责人明确。

## 1 选题

- 输入：观众问题、真实任务、热点或项目进展。
- 执行：按照 `02_内容方法/选题方法.md` 判断价值、证据、时效和制作成本。
- 输出：一个首选选题和少量备选。
- 完成条件：目标观众、观看理由、可见结果和需验证事实明确。

## 2 脚本与标题

- 输入：用户原话、观点、参考、必留镜头和选题结论。
- 执行：读取脚本、口播、标题与开头方法；助手补全未指定内容并核验事实。
- 输出：可阅读的 Word 脚本候选、标题候选和画面方向。
- 完成条件：用户明确脚本可以拍摄。

## 3 脚本锁定

- 输入：用户最后保存的确认稿。
- 执行：核对实际内容，统一为 `最终脚本.docx`；制作期旧版本进入可恢复归档；更新项目卡状态。
- 输出：唯一拍摄稿。
- 完成条件：正文、画面说明、标题、画幅和目标时长已确认。

## 4 拍摄

- 输入：锁定脚本和拍摄规范。
- 执行：先录自然度与收音测试，再按语义分段录制；原片进入受控本地目录。
- 输出：全部原片和必要补录。
- 完成条件：数量、规格、可播放性、首尾余量、小窗和敏感画面检查通过。

## 5 素材准备与确认

- 输入：原片、脚本、参考和事实来源。
- 执行：按素材准备规范完成 B-roll、证据画面、字幕、人物小窗、音效、动效与 BGM 采用判断。
- 输出：可审阅的素材预览和素材清单。
- 完成条件：用户确认素材，或集中修改意见已完成。

## 6 剪辑成片

- 输入：已确认素材、口播时间主轨和最终顺序。
- 执行：按剪辑、视觉、字幕和音频规范完成结构剪辑、合成、混音与技术检查。
- 输出：正式 MP4 或完整审片版。
- 完成条件：用户验收成片；画面、声音、字幕、隐私和关键边缘检查通过。

## 7 封面

- 输入：已确认成片和本条主题。
- 执行：按封面规范制作候选，通常比较稳妥延续版和创意放大版。
- 输出：一张最终封面。
- 完成条件：用户确认并通过手机缩略图与平台裁切检查。

## 8 发布

- 输入：最终成片、封面和成片兑现点。
- 执行：进入 `发布流程.md`，完成发布前检查、标题、正文、标签、声明和当次发布授权。
- 输出：真实发布记录。
- 完成条件：平台、时间、链接或作品 ID、实际发布稿和状态已记录；缺失项明确标为待补。

## 9 复盘与归档

- 输入：发布前假设、真实数据、观众反馈和制作记录。
- 执行：进入 `复盘流程.md`；区分观察、假设和可升级规则；执行分阶段清理。
- 输出：本条复盘、下一条首要改进和保留/移走清单。
- 完成条件：制作、发布、复盘状态分别更新；最终成果和证据完整；临时文件已处理。

## 分阶段清理

### 脚本锁定后

核对用户最后保存的 Word 内容，只保留正式拍摄稿；旧脚本版本进入带日期的可恢复归档，更新项目卡后再拍摄。

### 成片确认后、封面确认前

保留原片、最终 MP4、最终脚本、全部封面候选、当前可编辑主工程、证据来源和真实项目源码。可以移走 QA 截图、测试渲染、缩略图、波形、已完成用途的临时转写、一次性脚本、旧工程备份和可重建依赖。

### 封面确认并完成发布登记后

长期保留最终脚本、原片、成片、最终封面、事实和授权证据、必要源码、最终文件清单及发布复盘。可编辑工程是否保留由用户决定。所有过程文件先进入可恢复废纸篓，用户看过清单并确认后才永久清空。

## 最终交接检查

- [ ] MP4 可播放，画面和声音完整
- [ ] 封面已确认并通过裁切预览
- [ ] 最终脚本已正式命名，旧版本已可恢复归档
- [ ] 原片数量、大小或哈希未变化
- [ ] 证据来源和授权记录保留
- [ ] 发布文案、标签、链接和复盘记录保留
- [ ] 缓存、测试渲染、临时转写和辅助脚本已处理
- [ ] 用户看过保留/移走清单
- [ ] 用户决定是否保留可编辑工程
