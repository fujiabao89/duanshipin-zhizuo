# 发布前检查

## 文件与版本

- [ ] 最终 MP4、封面和脚本对应同一条视频与标题
- [ ] 分辨率、帧率、时长、音轨、文件大小和可播放性正常
- [ ] 当前版本不是测试片、审片版或已废弃修订版
- [ ] 成片从头到尾完整播放，末帧和退场正常

## 画面与字幕

- [ ] 普通字幕按完整画布居中，手机端清楚且不被平台 UI 遮挡
- [ ] 真人小窗四边无原屏幕细缝，转场前后位置一致
- [ ] 网址、书签、建议词、通知、邮箱、手机号和其他隐私已检查
- [ ] 无关平台名称、图标、口播和文字按用户制作约束处理
- [ ] 缩放、淡出、转场和快速运动帧没有漏遮挡或残留
- [ ] 真实论文、数据和网页来源可读，没有生成的假正文或假界面

## 声音

- [ ] 人声清楚，开头、正文和结尾音量关系合理
- [ ] 无吞字、突兀剪点、异常噪声、声画不同步或左右声道问题
- [ ] BGM 不盖人声；音效落点、密度和并列项一致性正确

## 封面与发布文字

- [ ] 手机缩略图可读，平台裁切没有切掉脸、标题或主题锚点
- [ ] 标题、封面、开头和成片承诺一致
- [ ] 正文、标签、专有名词、数字和互动承诺准确
- [ ] 实际发布稿与候选稿分开保存

## 外部素材与平台

- [ ] 外部视频、图片、音乐、论文、宣传片和 AI 生成内容已按版权规范核对
- [ ] 来源、授权或许可、署名、二创增量、版本名和 AI 标识真实
- [ ] 使用发布当天的平台规则中心、发文助手或上传预览复核当前状态
- [ ] 公开发布已获得当次明确授权

任何检查项异常都先记录证据、影响和最小修复。检查项本身不等于已经证明平台限制原因。
