# 标签与话题规范

## 先区分概念

- `#话题`：发布文案中的可点击主题词；
- 后台内容或创作者分类：有入口时如实选择；
- 平台对内容和受众的判断：不能靠几个井号锁死，也不能从标签顺序推导固定权重。

## 起步选择

每条通常选 3—5 个确实相关的话题，少一些也可以。这只是便于操作和复盘的默认值，不是平台上限或流量公式。

| 层次 | 建议 |
|---|---|
| 具体工具或对象 | 优先 1 个，本条确实以它为主 |
| 用途或场景 | 1—2 个，对应实际展示内容 |
| 内容类型或领域 | 0—1 个，教程确有教学时才用教程词 |
| 特定人群 | 内容确实解决该人群问题时使用 |
| 官方活动 | 核对当前资格、要求和入口 |
| 自有系列 | 用户确认需要系列归档后再建立 |

## 操作步骤

从工具名、任务和目标观众三个词开始，在发布当天搜索相关话题，查看结果是否属于希望进入的内容类别。历史热度不等于本条流量。使用当前发布页入口选择正确建议项，检查英文产品名、空格和分词，并保存实际使用的话题。

## 不采用的经验

不把“必须五个”“第一个占固定权重”“带热门必推流”“连续七天就能打准标签”等说法写成规则；不加无关娱乐、财经或情感词；不反复删除重发测试标签；不冒用参考博主名字；`#AI` 不等于完成 AI 内容声明。

跨平台发布时分别适配字段，不把抖音话题、TikTok 标签和 YouTube 后台 tags 当成同一功能。
