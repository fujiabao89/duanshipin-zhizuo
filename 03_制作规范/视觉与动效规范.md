# 视觉与动效规范

## 总原则

画面服务口播和证据，不为展示特效增加无关信息。动效按真实口播锚点推进；同一句最多一个主视觉重音。参考作品只学习结构和观看逻辑，不复制配色、字体、排版、人设或成品。

## 默认风格

- 简约、克制、易读，以字号、字重、留白和少量强调色建立层级；
- 避免炫光、复杂渐变、霓虹描边、多层粒子、连续弹跳、过度故障和廉价 AI 模板感；
- 能用静态文字讲清时，不强行动起来；
- 一屏一个主信息中心，人物、字幕、动态重音和证据不争抢阅读区。

## 主画面类型

- 概念冲击：一句核心判断接管主画面；
- 信息拆解：按口播逐层展开；
- 流程路径：节点和连线随因果推进；
- 数据证据：真实来源、年份和关键数值清晰可读；
- 录屏包装：保留真实操作，只做聚焦与解释；
- 前后对比：相同条件下展示差异；
- 结论收束：从前文提炼一个判断；
- 纯动效陪讲：只在没有合适实景或证据时使用。

相同信息在主画面已经讲清时，不再叠加第二套动态重音。

## 真人小窗

小窗作为独立连续顶层保留，裁切、缩放、圆角、描边和阴影整体复刻。主视觉以完整画布居中，不为了躲小窗整体偏心。静帧、运动帧、B-roll 切换和转场前后都要放大检查四边，不能露出原屏幕细缝。

## 论文和网页证据

优先让真实页面成为主背景，再叠加推近、高亮、翻译和批注。关键句在最终发布尺寸必须读清；证据层随镜头缩回或切走时同步退出，不能留下残影或假正文。

## 动态文字

通常提取 2—6 个字，最长不超过 8 个字；用于钩子、疑问、转折、数字和结论。基础动作以轻放大、翻入或逐字放大为主；震动、粒子和溶解只用于真正的剧情落点。动作完成后稳定停住，不循环漂浮。

### 动作词典

| 类型 | 适用 | 限制 |
|---|---|---|
| 钩子翻动 | 钩子、首次核心词 | 只翻一次，约 0.16—0.30 秒内稳定 |
| 疑问站起 | 疑问、意外、突然转折 | 站稳后短震 2—3 次并快速衰减 |
| 信息折叠滚入 | 数据标签和第二层信息 | 一次一行，按口播顺序进入 |
| 逐字旋入慢放大 | 数字增长、逐步建立 | 总错峰不超过约 0.50 秒，最终克制停稳 |
| 情绪微缩放 | 尴尬、惊讶、轻吐槽 | 只用于真实情绪，严肃证据不用综艺式缩放 |
| 粒子显形或溶解 | 知识揭示、章节级强调 | 低频使用，不遮挡证据、界面或表情 |
| 逐字放大镜 | 2—6 字连续重音 | 每个字只过一次峰值，同句不叠第二套强动画 |

一般进入约 0.16—0.28 秒，稳定或回弹约 0.08—0.16 秒，稳定停留至少 0.50—0.90 秒，退出约 0.14—0.24 秒。启动点控制在真实口播重音前后约 2 帧内。这些是工作范围，不是所有镜头的固定参数。

### 点音关系

| 音效 | 对应动作 |
|---|---|
| 轻 pop 或 tick | 轻弹出、贴合、文字落稳 |
| 短 whoosh | 滑入、折叠、滚入、推近 |
| ding | 疑问、转折、状态切换 |
| 轻 impact | 数字、结果、关键结论 |
| 颗粒质感音 | 粒子显形和溶解 |
| 低强度扫线音 | 论文高亮和证据条展开 |
| 语义拟声 | 心跳、弹簧、机械执行等含义明确的动作 |

一项动作最多一个主音效。任意 10 秒通常不超过 3 个主动态文字，任意 3 秒不超过 2 个明显点音；开头 3 秒最多连续两个重音事件，随后留稳定时间。

## 品牌与界面

生成层不新增无关平台图标、仿 Logo 或品牌拼贴。用户要求后续作品从脚本、录制和剪辑阶段检查无关平台名称、网址、书签和界面；这是制作约束，不是“出现就必然受限”的平台结论。
