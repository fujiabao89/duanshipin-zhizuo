# 工具与工作流评估

## 状态定义

| 状态 | 含义 |
|---|---|
| 当前采用 | 已解决真实阻塞并进入现行流程 |
| 当前借鉴 | 只吸收适合的方法，不整套接入 |
| 到点复核 | 达到明确条件后再测试 |
| 待验证 | 证据或实测不足 |
| 不采用 | 当前价值、成本或风险不匹配 |

## 候选总表

| 工具 | 当前判断 | 已确认价值 | 复核条件与边界 |
|---|---|---|---|
| HyperFrames | 当前采用 | 第001条用 0.8.6 完成整片；第002条用 0.8.35 完成整片，验证录屏、小窗、字幕、动效和渲染 | 继续观察模板复用、改稿速度和重复渲染稳定性；工程固定版本，升级在副本中验证 |
| Remotion 官方 Codex 插件 | 已安装，待隔离样片 | 适合 React 程序化视频、参数化和批量生成 | 不替代当前 HyperFrames；达到批量变体、产品化生成或明确能力缺口时，用同素材 10—15 秒样片对比 |
| 剪映／CapCut MCP | 待验证 | 可能生成可继续手工编辑的草稿 | 未发现官方实现；第三方草稿格式、云上传和删除权限有风险，只能用复制素材、空白草稿和独立目录测试 |
| GSAP skills | 当前借鉴 | 时间线、缓动、SplitText、Flip、SVG 和性能方法可辅助 HyperFrames | 只在具体镜头需要时选用；网页滚动和交互不能驱动确定性视频时间线 |
| video-shotcraft | 到点复核 | 产品展示分镜和 Remotion 配方 | 适合网站或产品展示段，不替代真人口播内容判断；先做 10—20 秒样片 |
| cheat-on-content | 已安装，前端方法可借鉴 | 热点整理、对标拆解、选题推荐和复盘流程 | 自动采集源未配置，评分偏观点视频，不能预测具体播放；需映射现有中文结构后再完整实跑 |
| Auto-Editor | 当前借鉴 | 标记静音和候选剪点 | 不能自动删完直接当终稿 |
| Subtitle Edit | 到点复核 | 转写、波形校时和字幕修正 | 字幕校对成为瓶颈时再安装，机器转写必须校对专名 |
| cutcli | 到点复核 | 生成可编辑 CapCut/剪映草稿 | 先审查源码、网络和云能力，只用非敏感样片测试 |
| pyJianYingDraft | 当前不采用 | 可生成剪映草稿 | macOS 不能自动导出，与当前工作流不匹配 |
| PySceneDetect | 当前不采用 | 自动找硬切和淡入淡出 | 已按语义分段录制时收益低 |
| LosslessCut | 备用 | 无重编码裁切、拆轨和合并 | 只在大文件预处理时使用，不能完成复杂合成 |
| OpenTimelineIO | 到点复核 | 跨专业剪辑软件交换时间线 | 只有确定交接 Premiere、Resolve 或 FCP 时有价值 |
| Frame.io／CapCut Share | 到点复核 | 按时间评论、版本对比和审片 | 聊天反馈无法管理时再接入外部服务 |

## 维护规则

收到新工具先核对官方来源、版本、费用、许可、安全和数据权限，再判断当前价值与未来触发条件。“已安装”不等于“已采用”，“文档声称支持”不等于“已经实测”。候选工具不能挤占当前主任务，但也不因暂时不用而删除。
