# 封面管理规则

## 用途

本文件夹统一保存账号各期视频已经确认的最终封面，以及经过用户明确确认后形成的封面设计规则。

## 确认规则

1. 封面分析、参考图、提示词和生成候选均属于讨论稿，不自动成为正式规范。
2. 只有用户查看实际生成结果并明确表示认可后，才把对应的人物形象、构图、字体、配色或其他设计特点写入本文件。
3. 后续封面可以参考已经确认的规则，但仍须结合当期视频内容设计，不能机械套用。

## 保存规则

1. 每条视频在本文件夹中只保存一张已经确认的最终封面。
2. 最终封面与短视频制作、剪辑目录使用同一个基准名，固定为“第X条：视频标题.png”，例如：`第2条：WorkBuddy更香？.png`。冒号使用中文全角符号。
3. 未确认的候选图和中间生成稿不放入本文件夹；它们只可暂存在当期内容目录，选定后移入可恢复废纸篓。
4. 视频与封面全部确认后，按照项目清理规则处理过程中产生的临时文件。

## 已确认的封面设计规范

以下规则来自用户对第1条实际封面第一版的确认；后续按每期内容灵活运用。

1. 人物的脸以本人照片为身份参考，保留可辨认的五官、眼镜与发型；身体、服装、动作、道具和背景均根据当期封面重新生成。
2. 可以使用夸张的大头小身体、前景道具和不符合现实比例的构图制造趣味，但人物身体仍表现为成年人。
3. 画面必须出现一个能点明视频重点的识别元素；其他背景、身份和情境允许根据主题发挥想象，不要求与视频内容逐项对应。
4. 封面首先追求创意、吸引力和缩略图辨识度，画面要饱满、有前后层次，避免无意义的大面积留白。
5. 标题采用粗重、醒目、带清晰描边和紧凑阴影的形式，保证缩小后仍能看清。文字颜色根据每期画面变化，不固定为全黄色。
6. 第1条确认的画面方向为写实人脸与生成场景融合：本人操作虚构的 Codex 造物机，机器展示个人网站和简历成果。

- 第2条《WorkBuddy更香？》：`第2条：WorkBuddy更香？.png`。用户已将其用于正式发布。
