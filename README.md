# 短视频制作工作流仓库

这不是一个软件项目，而是一套可以通过 GitHub 阅读、传递和复用的短视频制作工作流与知识库。它记录从选题、脚本、拍摄、素材准备、剪辑、封面、发布到复盘的完整方法，并用真实视频案例验证和修正流程。

## 适合谁

- 希望建立稳定短视频生产流程的创作者或小团队；
- 需要让 AI Agent 按项目规则协作的人；
- 希望复用真实案例经验，又不把单条视频的临时做法误当成通用规则的人。

## 快速开始

1. 先读 [项目定位](00_项目说明/项目定位.md) 和 [使用说明](00_项目说明/使用说明.md)。
2. 制作一条新视频时，从 [单条视频完整流程](01_总工作流/单条视频完整流程.md) 开始。
3. 进入具体阶段后，只读取对应的内容方法、制作规范或发布规范。
4. 处理已有视频时，先读 `06_视频案例/对应视频/项目卡.md`。
5. AI Agent 应先读根目录 [AGENTS.md](AGENTS.md)，再按任务路由读取文件。

## 目录

| 目录 | 职责 |
|---|---|
| `00_项目说明` | 项目定位、使用方式、当前版本和重要流程变更 |
| `01_总工作流` | 定义各阶段的顺序、输入、输出和完成条件 |
| `02_内容方法` | 选题、脚本、口播、标题和开头的方法 |
| `03_制作规范` | 拍摄、素材、剪辑、视觉、字幕和音频标准 |
| `04_发布规范` | 封面、发布文案、标签、发布检查和版权要求 |
| `05_运营与研究` | 账号策略、选题池、账号观察、工具评估和实验记录 |
| `06_视频案例` | 每条真实视频的目标、特殊要求、制作记录和发布复盘 |
| `07_资产库` | 可复用的封面、动效、音效和 B-roll 资产 |
| `99_归档` | 已退出当前体系、但仍有历史价值的旧资料 |
